# Project Hero

Este jogo foi desenvolvido como parte da disciplina de Programação 2, com o objetivo de criar uma experiência multiplayer para Windows utilizando a Unreal Engine 5. Nele, os jogadores controlam um trio de aventureiros que trabalham em equipe para enfrentar inimigos, ajudar os moradores locais, descobrir segredos e explorar um mundo de fantasia em uma aventura cooperativa com elementos clássicos de RPG.

---

## Estrutura do Projeto

| Arquivo                           | Descrição                                                     |
|-----------------------------------|---------------------------------------------------------------|
| `BP_Knight BP_Ranger BP_Witch`    | Gerencia os comandos de movimentação e Ataques dos jogadores. |
| `AB_Knight AB_Ranger AB_Witch`    | Controla as animações e eventos dos jogadores.                |
| `BP_GameMode`                     | Gerencia a conexão entre os jogadores e seleção de personagem.|
